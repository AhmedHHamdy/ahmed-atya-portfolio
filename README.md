# Ahmed Atya Portfolio

The original compiled multi-page portfolio has been migrated to a maintainable Next.js App Router project.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Home
- `/about` — About
- `/portfolio` — Portfolio
- `/contact` — Contact

The former `.html` URLs redirect to their corresponding Next.js routes.
